# Seedscape bridge (short)

**Seed-driven MIDI leaves the computer for the Roland S-1; the same seed and sliders drive p5.js WEBGL.** Knobs and keys on the S-1 come back over USB MIDI into the bridge, which forwards them to the browser so the column responds to your hands while the phone still steers global density and tempo.
