Invisible Layer

A Canvas2D motion map the viewer never sees — red, green, and blue channels encoding spatial operators — feeds a GPU volume, optional code veil, and soundscape from the same field.

R smears XY raster displacement. G drives spectrum and palette tiles. B pushes depth through a voxel field. The visible work is what the invisible layer authorizes.
