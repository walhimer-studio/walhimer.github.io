## What you are selling (30 seconds)

**A signed, editioned generative artwork that lives on the wall** — like a painting or photograph, but the image is alive: it generates in real time from a fixed artistic seed, runs on museum hours, and needs **no Wi‑Fi, no apps, and no IT department**.

The buyer hangs it, plugs it in, and lives with it. If anything fails, the studio ships a replacement module — local installer swaps it. **Plug in. Nothing else.**

Target placement: **$4,000–5,000** per unit (43" class; final quote per edition and framing).

## How to position vs other media

**vs. painting / photography**  
Same wall, same permanence — but the surface **breathes**. Not a reproduction; each edition number is a **distinct seed** (same species, different individual).

**vs. NFT / on-chain**  
No wallet, no platform risk, no screen in a closet. **Object-first** — suited to advisors whose clients want physical presence.

**vs. plotter / print generative**  
The work was never meant to freeze as ink. These pieces have **lifespan, sound, and surrender** — the screen is the native body.

**vs. “digital art frame” (Meural, etc.)**  
Not a subscription slideshow. **One artist, one work, one edition** — certificate, studio support, museum hours.

**vs. room-scale installation**  
This is the **entry SKU**. Same artist; full room (LED, projectors, distributed systems) is a later commission tier.

## Objection handling

**“Is it just a TV?”**  
No — the TV is the canvas. The work is the **generative system and edition** inside it, same way a lithograph is not “just paper.”

**“Will it need updates?”**  
No cloud dependency. Unit runs a fixed artwork build. Studio handles replacements.

**“What about Wi‑Fi and ads?”**  
Display is **never joined to the internet**. No smart-TV setup on site.

**“Is my face sent to the cloud?”** *(Witness Mirror only)*  
No. Processing stays **on the device**. Session data is not uploaded in the standard edition.

**“Why not an NFT?”**  
Artist is prioritizing **physical presence and consultant placement** — object collectors and lobbies, not token markets.

## Suggested advisor workflow

1. **Identify wall** — lobby, residence, institution (power + mount clearance).  
2. **Choose series** — send client to [mark-walhimer.com](https://mark-walhimer.com) sketches or studio PDF for the four APs.

4. **Ship to local installer** — studio provides one-pager; advisor or owner hires mount (any AV/TV mount vendor).
