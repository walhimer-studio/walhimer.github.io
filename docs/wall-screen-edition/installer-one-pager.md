## What you are installing

A **complete wall artwork** — not a consumer TV setup.

| Component | Notes |
|-----------|--------|
| **43" display** | Standard LCD panel (Hisense or studio-specified SKU). **Dumb screen** — HDMI in only. Do **not** connect to Wi‑Fi or run smart-TV setup. |
| **Compute module** | Small fanless box (mounted behind panel or in cavity). Already configured. **Do not** open except on studio instruction. |
| **Mount** | VESA or studio-supplied wall bracket — same as a medium flat-panel TV. |
| **Power** | One cord to outlet (or one timed outlet — see schedule below). |
| **Optional QR label** | Small sticker, bottom corner — for visitor phone link. Does not require owner Wi‑Fi. |

Internal **HDMI** and power between compute and display are **pre-connected at the studio**.

## Install steps

### 1. Site check

- [ ] Wall can support ~40–50 lb (panel + mount) — use studs or appropriate anchors  
- [ ] Outlet within reach of power cord (or timed outlet installed)  
- [ ] No direct sun on screen if avoidable (lobby glare OK — studio calibrates for typical indoor light)  
- [ ] For **Witness Mirror** units only: camera faces viewer area (~1–3 m); no obstruction  

### 2. Mount display

- Install wall bracket per bracket manufacturer instructions.  
- Hang panel level; secure all fasteners.  
- Compute module: attach behind panel or in approved cavity — **ventilation gap ≥ 2 cm** if enclosed.

### 3. Power

- Plug **one** power path (studio ships either a single cord to a power strip inside the assembly, or one visible cord — follow label on unit).  
- **Do not** power the TV and compute from separate unsynchronized timers unless the studio sheet says so.

### 4. First power-on

1. Switch on power (or wait for scheduled outlet if pre-set to 8:00).  
2. Allow **up to 60 seconds** — artwork appears fullscreen automatically.  
3. **No keyboard or mouse required.**  
4. Confirm: image fills screen · motion/generation visible · sound at low lobby level (if this edition includes audio).  

### 5. Schedule (typical museum / lobby)

| Setting | Default |
|---------|---------|
| **On** | ~8:00 AM local |
| **Off** | ~9:00 PM local |

Pre-configured at studio. **Do not change clock or OS settings.** If hours must change, contact studio.

### 6. Handoff to owner

- Confirm artwork runs through one full on-cycle if possible.  
- Leave **certificate / edition card** with owner (studio ships separately if not in box).  
- Owner sign-off: *[install receipt — optional]*

## Troubleshooting (installer only)

| Symptom | Action |
|---------|--------|
| Black screen after 60s | Check power to **both** display and compute; re-seat HDMI **only if studio-approved** |
| Washed-out color | Note for studio — may be TV picture mode; **do not** run internet-based “ firmware update” |
| No sound | Check volume is not muted on compute (studio preset); check speaker path if external speaker shipped |
| Screen on outside 8–9 window | Note time; contact studio — do not edit system clock |

**Do not** factory-reset the TV or re-image the compute module.

---

## Replacement (field swap)

If studio ships a **replacement compute module** or **replacement display**:

1. Power **off** unit.  
2. Swap the failed part only (HDMI + power + mount screws as needed).  
3. Power on; wait 60s; confirm artwork.  
4. Return failed part to studio if label instructs — packing uses original display box when provided.  

No software install on site.
