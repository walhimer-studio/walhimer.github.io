# Artist Statement — Mark Walhimer

I use code and real-time systems to think about acceptance, control, and agency. I build machine aesthetics—generative environments that run live, wear down, and sometimes surrender—so users can feel the tension between holding on and releasing, not just look at a finished picture. My work moves from numbered digital fragments toward room-scale and site-specific installations where strangers become co-authors, and emergence replaces a single author’s intention.

Mark Walhimer (b. 1964) · markwalhimer.com
