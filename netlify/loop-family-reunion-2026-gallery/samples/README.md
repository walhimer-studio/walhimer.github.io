# Salamander Grand Piano — pentatonic subset

**Salamander Grand Piano** (Yamaha C5) — Alexander Holm, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

Reinstall after samples go missing:

```bash
python3 _scripts/install_salamander_samples.py
# then copy pentatonic mp3 roots into this folder:
# cp ../sketches/the-wrong-biennale/the-wrong-eclipse-august-2026/samples/salamander/pentatonic/*.mp3 ./samples/
```

Required roots: `C2`, `A2`, `Ds2`, `Fs2`, `C3`, `A3`, `Ds3`, `Fs3`, … through `Ds6`.
