## Description

Invisible Layer names emotions made visible — emotions shown in real time. The work renders that invisible layer as a votive.

Real-time animation using invisible layers: green scanners and red layers (plus blue depth probes) on a hidden Canvas2D motion map → spectrum and raster on the GPU via Three.js RGB→XYZ volume feedback; seed-driven Machine DNA, lifeline, and sonification; self-contained JavaScript, modes/LED/lifeline, no external CDN.
