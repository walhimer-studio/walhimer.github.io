# Witness Mirror (live)

Technology as witness — **live camera**, real-time counterpoint. Browser face-api.js (7 expressions) + point-word cues while you read or evoke. Record webm for offline DeepFace review on [Witness Mirror (1s)](./witness-mirror-1s.md).

**Live:** https://mark-walhimer.com/sketches/digital-twin/witness-mirror-live.html

| Mode | Stack |
|------|--------|
| **Live** | face-api.js · tiny face detector · expression net · vendored under `js/face-api/` |
| **Point** | Seven-word cue buttons — what you're evoking (story layer, planned) |
| **Counterpoint** | ML dominant expression · highlights disagreement / masking |
| **Record** | MediaRecorder → `.webm` → `analyze_testimony_emotions.py` → 1s/5s review |
