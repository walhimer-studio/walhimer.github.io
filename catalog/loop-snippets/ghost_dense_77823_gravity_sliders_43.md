## Wall framing chronicle (43″ / 55″)

This file is the studio reference for **Surrender / Ghost machines on 43″ and 55″** Hisense-class panels (same aspect, same full-window canvas):

- Canvas fills the window (no letterbox crop of the buffer).
- Machine scale via **camera distance** (`CAM_PULL`), not canvas shrink.
- Portrait mount + landscape HDMI: software rotate in local kiosk, or OS rotation when available.
- Do not “fix” framing by stretching CSS; keep aspect honest.

Future wall pieces in this family should start from this framing language unless a new chronicle supersedes it.
