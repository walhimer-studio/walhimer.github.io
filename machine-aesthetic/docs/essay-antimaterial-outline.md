## I. Opening — the votive machine (~120 words)

**Purpose:** Name the work as *space*, not screen; establish Surrender Machines + PoC title.

**Say:**

- Interactive **three-room votive machine** — you enter, not consume an image.
- “Struggles,” “ego,” “pride” — **none of that is true**; only code running.
- **Surrender Machines** = larger project; **MachineDNA** = seed, metabolism, decay; built to **run down**, not loop forever.
- **Loop Art Critique** = this submission, **proof of concept** in the browser.

**Avoid:** Tech stack, curator names, selling.

**Anchor line (optional):**  
*It is built only from code, running.*

---

## II. What you witness — walk, break, end (~150 words)

**Purpose:** Describe visitor experience before theory.

**Say:**

- Walk corridors and chambers; mechanisms multiply, slip, break.
- **Lifespan / clock** you did not set; end you cannot override.
- **Mechanical Sigh** — low hum, blurred field, release of “desire to compute.”
- Work becomes **relic**, not tool; performance **finally stops** (let emptiness/surrender read through structure—do not name Zen or Buddhism).

**Avoid:** Zen, Buddhist doctrine, “grasping/emptiness” lecture; slider detail (save for §III); file formats.

**Anchor line:**  
*Something that insisted on performing finally stops.*

---

## III. Ghost in the machine — projection (~130 words)

**Purpose:** Ryle; anger / ego / attachment as **visitor’s**, not machine’s.

**Say:**

- **Gilbert Ryle** — ghost in the machine = projecting inner life onto technical objects.
- Sliders labeled anger, ego, attachment because they are **ours**.
- We want machines without those states; we see ourselves anyway.
- Work **stages** confusion to make release possible — does not “fix” projection.

**Avoid:** Zen/Buddhist labels (attachment slider + surrender + zero state are enough); SO-101; Tresset name-dropping (optional footnote only).

**Anchor line:**  
*I am not correcting that confusion. I am staging it so it can be released.*

---

## IV. Counter-production and Simondon — misuse by design (~150 words)

**Purpose:** Connect to Doreen’s framework in **your** words; death as architecture.

**Say:**

- Code normally = efficiency, control, infinite repeatability; here **misused** toward death.
- Raise sliders → gears strain and fail; **terminal fade** regardless of visitor.
- **Doreen Ríos — counter-production:** beyond design intent; not aestheticizing correct operation.
- **Gilbert Simondon —** object has own **milieu**, own **end**.
- You built conditions; you cannot take the end back once it runs.

**Avoid:** Veblen goods paragraph (unless brief); Lumen; three-project survey unless she asks.

**Anchor line:**  
*Architecture aimed at exhaustion.*

---

## V. Surrender, zero state, pride of building (~140 words)

**Purpose:** Emotional climax; industrial design; cost of release.

**Say:**

- **Surrender** ≠ absence of feeling; feeling was **yours all along**.
- Machine never angry / proud / sighing.
- **Zero state:** one clean tone, no spectacle.
- Machine must be **worth keeping** for surrender to matter.
- **Industrial design** training — between hand and system; **pride of building** load-bearing and must go.

**Avoid:** Mechanical how-to; gear math.

**Anchor line:**  
*The pride of having built something precise is load-bearing in the work. That pride is also exactly what has to go.*

---

## VI. Kernel, co-creation, three states (~150 words)

**Purpose:** One clock; Emergent DNA vocabulary; digital → object → installation.

**Say:**

- **Kernel** = virtual mechatronics (load, friction, jam) — not decoration + soundtrack.
- One state → sight + sound (**metabolism**, not paired tracks).
- Visitors **co-authors of stress**; **misfires** = honest record in time.
- **Emergent DNA** (short): co-creation · surrender over ego · **kintsugi** · one clock · species not file.
- **Three states:** digital (this room) · object · physical installation — same seed/temperament/end, different **host**.

**Avoid:** OSC port numbers; Pi / switch; Phase 0–3 OF port.

**Anchor line:**  
*What changes is host. What remains is temperament, seed, and end.*

---

## VII. What this submission is — PoC, no market (~120 words)

**Purpose:** Align with Doreen’s commodification question; set expectations for antimaterial.

**Say:**

- **Loop Art Critique** = PoC: votive + ghost + lifespan + zero state.
- Finishing browser build → **freeze** → stable link + **video**.
- OF / Pd / light = future **bodies**, same species — not new artworks.
- **Not selling now:** no screenshots, tokens, luxury edition as counter-production.
- **You** raised Veblen / commodification (Doreen took it up in her curatorial text) → **postponement**; loop is the work.

**Avoid:** Pricing; edition size; Console SKU.

**Anchor line:**  
*Let it be useless in the market sense.*

---

## VIII. Sound, light, install (optional — ~80 words)

**Purpose:** One paragraph on ears/light without hardware lead.

**Say:**

- Sound = **friction** of mechanism (Pd ← machine state).
- LED / light = same ethic as code gears (one protocol, dumb receivers).
- Synth may **voice** live; **clock** stays with mechanism.
- Browser asks the question; install kit survives a gallery evening.

**Avoid:** Teensy, Matrix Portal, arduino, Roland model number unless one phrase.

---

## IX. Open question — foreign tools / remaking (~100 words)

**Purpose:** Invite Doreen’s colonial / Mexican modernist line; don’t fake an answer.

**Say:**

- Tools (browser, dominant corpora, later C++) = **foreign technical objects**.
- Counter-production in her lineage = **remaking from inside**.
- Honest: not sure if practice **remakes** or **diagnoses while fluent inside**.
- Votive room as **evidence**: produces experience; dies on schedule; projection drops to tone.

**Avoid:** Claiming decolonial mastery; US-Mexico politics you haven’t lived in the work.

**Anchor line:**  
*I offer the votive room as evidence toward an answer.*

---

## X. Close — instruction to visitor (~40 words)

**Purpose:** Memorable last line; no new concepts.

**Say:**

- Walk until **fade**.
- Proof ≠ code mimics person.
- Proof = feelings projected onto system return to geometry, clock, signal — **relief**.

**Avoid:** CTA to buy; social handles.

**Anchor line:**  
*Hear, in that return, something like relief.*
